# Библиотека фигур

Библиотека Python для вычисления площадей геометрических фигур, таких как круги и треугольники. Поддерживает ввод в виде длины сторон или точек. Включает проверку правильности треугольников и прямоугольных треугольников.

## Функции

- Вычисление площади окружности по радиусу (необязательная центральная точка).
- Вычислить площадь треугольника по сторонам или точкам (используя формулу Херона или упрощенную для прямоугольных треугольников).
- Проверить, является ли треугольник прямоугольным.
- Возможность расширения для других фигур с помощью класса abstract Figure.
- Включены Unit тесты.
